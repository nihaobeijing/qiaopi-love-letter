# 迭代教训与用户纠正记录

## 用户纠正的关键问题

### 第1版错误：太像作文
- 我写的："街灯初上，想起家中灶火温粥，恍惚间已闻到饭香。带了你爱吃的点心，你不必再张罗。风凉，勿出门迎，灯亮着便是归处。"
- 用户反馈："你懂个锤子"
- 问题：太文艺、太像写作文，不像真人写信

### 第2版错误：太端着
- 我写的："今日事了，已在归途。路上给你带了你爱吃的，别问是什么，回见。灯开着就行，几分钟到。"
- 用户反馈："还是不够聪明啊"
- 问题：虽然口语化了，但没有侨批的古朴感

### 第3版错误：格式对但灵魂不对
- 我写的："今日事了，已在归途。街灯初上，想起家中灶火温粥，恍惚间已闻到饭香。你不必再张罗，我片刻便到。"
- 用户反馈："还是没达到我的预期"
- 问题：格式对了，但缺少"闷骚"感——表面说别的，心里想的是另一回事

### 第4版错误：太正式
- 我写的：用了"夫 手书"结尾
- 用户反馈：需要更贴近电影原版

### 用户提供的正确模板
```
吾爱，展信安。
手头诸事已然了结，即刻动身奔赴于你。
长路漫漫，归心急切，只盼早日与你相见。
不必牵挂，静候相逢。
```

### 最终正确版本（用户确认"对味了"）
```
吾兄，展信安。
今日路上车马拥挤，皆是赶着谋生的人。
我在其中，也在赶路。
你先忙着，我稍后便到。
勿念。
```

## 核心教训

1. **不要写得太文艺**——不是诗词创作，是普通人写家书
2. **不要写得太口语**——要有民国古朴感，但不晦涩
3. **要"闷骚"**——表面说别的事（路上人多、天气、吃的），心里想的是对方
4. **短句一行一行**——和手写侨批排版一致
5. **结尾极简**——勿念、安好、静候，不要多余抒情
6. **参考电影原版用词**——"免担忧"、"切要平安"、"你免挂念"
